# Feature Parity Checklist

- ✅ Auto-attack & configurable weapon cooldowns
- 🟡 Multiple concurrent weapons (basic unlock exists but lacks enemy parity)
- 🟡 Enemy waves with difficulty scaling (time-based only, limited scaling curves)
- ❌ Empowered / elite / boss enemies (placeholders only)
- 🟡 XP, levels, upgrade choices (XP orbs + level signal, but upgrades are minimal)
- 🟡 High entity performance (pools exist yet stutter after ~150 simultaneous bodies)
- 🟡 Autoplay / simulation runner (manual + timed sims exist, no input driver yet)
- 🟡 Config-driven parameters for balancing (env overrides exist but lack schema validation)

Legend: ✅ Implemented | 🟡 Partially implemented | ❌ Missing
